# homebrew-tap

Homebrew tap for [egent-code-plexus](https://github.com/coseto6125/egent-code-plexus) — an LLM-first polyglot code intelligence graph (`ecp` CLI).

## Install

```bash
brew tap coseto6125/tap
brew install egent-code-plexus
```

Verify:

```bash
ecp --version
ecp mcp tools
```

## How this tap is maintained

Formulae in `Formula/` are auto-generated by the upstream repo's release CI on every `v*` tag push (see [`.github/workflows/release.yml`](https://github.com/coseto6125/egent-code-plexus/blob/main/.github/workflows/release.yml) — the `homebrew-tap` job). Do not edit `Formula/*.rb` by hand; changes will be overwritten on next release.

The formula uses pre-built `.tar.gz` artifacts from upstream GitHub Releases (signed with Sigstore + SLSA provenance), keyed off the macOS arch (`aarch64-apple-darwin` or `x86_64-apple-darwin`).
